# Anime NOVA v3.5 — النسخة المستقلة لتطبيق الأندرويد (Android Phone & Android TV)

هذا المجلد (`nova2-android/`) يحتوي على **مشروع تطبيق الأندرويد المستقل بالكامل** لتطبيق **Anime NOVA (الإصدار الشامل V3.5)** للهواتف الذكية وشاشات **Android TV**، ويضم جميع التعديلات والمميزات الحديثة التي تم تطويرها:

---

## أبرز المميزات المدمجة في نسخة الأندرويد (`nova2-android`)

1. **واجهة البداية الشاملة والأنيقة (`BrandSplash` / `BootstrapScreen`)**:
   - تصميم موسّع وشامل يعرض حالة خوادم البث المتصلة، شعار Anime NOVA، والركائز الـ 6 للتطبيق (أنمي مترجم وأفلام، مدبلج وسبيستون، مانجا ومانهوا، تنزيل بلا إنترنت، مكتبتك السحابية، للهاتف والتلفاز).
2. **نافذة إعلان تيليجرام المتجاوبة مع الثيم (`TelegramAnnouncementDialog`)**:
   - تتبدل ألوانها تلقائياً بين **الثيم الأسود الملكي (OLED)** و**الثيم الأبيض الساطع**.
3. **المشغل الداخلي الاحترافي (`RiftPlayerScreen.kt` — Media3 ExoPlayer)**:
   - شريط تقدم (Seekbar) مكبر ومريح للعين بتدرج زمردي-سماوي (`#10B981 -> #06B6D4 -> #38BDF8`) مع مؤشر دائري بحافة بيضاء ناصعة وعلامات صفراء لتخطي المقدمة والنهاية.
   - رفع زر **«تخطي المقدمة ⏭»** للأعلى لعدم التداخل مع شريط التقدم.
   - زر إيقاف/تشغيل دائري داكن أنيق متناسق مع بقية الأزرار.
   - إخفاء تلقائي لأزرار المشغل بعد `3.5` ثانية واستجابة فورية للمس الشاشة.
4. **قسم المانجا والمانهوا (`MangaScreens.kt`)**:
   - قائمة منسدلة أنيقة لاختيار الفصول (`قائمة اختيار الفصول السريعة`) داخل صفحة تفاصيل المانجا وداخل قارئ الفصول في الأعلى مع البحث الفوري والانتقال السلس للفصل الثاني وما بعده.
5. **قسم التصفح وتصنيف أفلام الأنمي (`CatalogScreens.kt`)**:
   - إضافة تصنيف **«🎬 أفلام الأنمي»**.
   - توافق كامل لشريط ونافذة الفلتر مع **الثيم الأبيض الساطع (`أبيض ساطع`)**.
   - إزالة عبارة «عرض أفقي كامل» من أعلى التريلر وتصميم نافذة التريلر السينمائية (`OFFICIAL TRAILER · 1080p HD`).
6. **قسم التنزيلات (`LibraryScreens.kt`)**:
   - بوسترات أنمي نظيفة بدون علامة الفيديو عليها.
   - إضافة زر **«⏸ إيقاف مؤقت»** و**«▶ استئناف التنزيل»** بجانب الحذف والتشغيل الأوفلاين.
7. **الملف الشخصي، إدارة الحساب في صفحة كاملة، وخيار «ادعمني» (`LibraryScreens.kt`)**:
   - فتح قسم **«إدارة الحساب»** في صفحة كاملة مستقلة (`AccountManagementFullScreen`).
   - حذف خانة البريد اليدوي في تسجيل دخول Google، وحذف وضع صورة البروفايل عبر رابط، وحذف نشر أو بحث التعليقات من سجل التعليقات في الملف الشخصي.
   - إضافة بطاقة ونافذة **«ادعمني ليستمر التطبيق بالعمل مجاناً»** تحت Nova Premium بخيار **«ادعمني بنجوم أو هدايا تلجرام ⭐🎁»**، وعند اختيار أي مبلغ (`1$`، `3$`، `5$`) يظهر زر **«اذهب إلى تلجرام»** مباشرة.
8. **التضمين الكامل للأصول (`assets/webapp/` + `NovaEmbeddedAppScreen.kt`)**:
   - يضم المشروع أيضاً النسخة المجمّعة الكاملة لواجهة التطبيق داخل `app/src/main/assets/webapp/` عبر `WebViewAssetLoader` لتعمل بكامل تفاصيلها وتأثيراتها أوفلاين وأونلاين جنباً إلى جنب مع شاشات Jetpack Compose الأصلية.

---

## طريقة استخراج ملف الـ APK عبر GitHub Actions (تلقائياً بدون كمبيوتر)

1. ادفع (Push) التغييرات إلى مستودعك في **GitHub**.
2. افتح تبويب **Actions** في مستودعك على GitHub، وستجد workflow باسم **`Build Anime NOVA Android APK (v3.5)`** يعمل تلقائياً.
3. بعد اكتمال البناء، اضغط على الـ Workflow وحمّل ملف **`Anime-NOVA-v3.5-Android-APK`** لتثبيته مباشرة على هاتفك أو شاشة Android TV.

## طريقة البناء المحلي عبر Android Studio

1. افتح مجلد **`nova2-android`** مباشرة داخل **Android Studio**.
2. اضغط **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
